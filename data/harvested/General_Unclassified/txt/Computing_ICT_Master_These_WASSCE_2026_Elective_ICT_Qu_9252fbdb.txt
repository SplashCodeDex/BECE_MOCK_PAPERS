Review these core concepts today to identify your weak spots before it’s too late.
Section 1: Data Systems & Digital Literacy
1. (a) Explain data representation.
[4 marks]
(b) State two differences between binary number system and decimal number system.
[4 marks]
(c) What is a
Decision Support System
?
[2 marks]
2. (a) What is
digital culture
?
[2 marks]
(b) Explain two roles of the Internet in everyday life and its impact on information sharing.
[4 marks]
(c) State two benefits of ICT tools in education.
[4 marks]
Section 2: Hardware & Network Performance
3. (a) Describe the following ports on the computer’s system unit:
(i) parallel port;
(ii) video adapter port. [6 marks]
(b) State two negative factors that affect the performance of a computer network.
[4 marks]
Section 3: Desktop Publishing & Software Applications
4. (a) Explain the following terminologies as used in Desktop publishing:
(i) frame;
(ii) handles. [4 marks]
(b) Outline the reason for the display of the error message #NAME? in a Spreadsheet application.
[2 marks]
(c) State one function of each of the following software:
(i) utility program;
(ii) diagnostic program. [4 marks]
Section 4: Networking Protocols & Security
5. The home network of a family has Internet access. A server is configured to control user access to the network. To have access to the network, each user logs in with a username and password. The sequence of activities to log into the network are as follows:
i. Check user credentials in the database.
ii. Enter username and password to log in;
iii. Grant user access to the network.
(a) Rearrange the sequence of activities in the correct order and use it to draw a flowchart.
[6 marks]
(b) State one function of each of the following network terminologies:
(i) firewall;
(ii) access control. [4 marks]
Section 5: Practical Task — Microsoft Publisher
Practical Scenario:
Your group has been inspired by developments in the IT industry. This has led to the establishment of an IT school to offer short training courses.
Task:
Create a brochure using Microsoft Publisher to provide potential students with information.
(a) Create a six-panel tri-fold brochure.
(b) Use two separate pages with three panels on each page.
(c) Set the pages to allow front-and-back printing.
(d) Include the school name, location, and contact information.
(e) Add details about courses offered and include a catchy slogan.
(f) Apply landscape page orientation.
(g) Set all page margins to 0.5 inches.
(h) Use text boxes, graphics, horizontal lines, bullets, and drop caps appropriately.
(i) Vary font styles and sizes while maintaining consistency.
(j) Save the file as
BROCHURE
in both Publisher and PDF formats. [15 marks]

Ensure you can explain the “why” behind networking protocols and demonstrate the “how” in software applications. Keep practicing, stay focused, and go get those marks!
